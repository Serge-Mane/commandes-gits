# commandes git
- Liste ds commandes git

## git init 
- Permet d'initialiser un répertoire 

## git add .
- Permet d'ajouter un fichier ou une modiffication dans le stagging

## git commit 
- Permet d'enregistrer en locale les modiffications

## git status 
- Permet de veriffier le statut du répertoire
- Permet de lister les moddifications à traiter

## git log
- Permet de lister les moddifications en local

## git log --oneline
 - Permet de lister les moddifications pousser en ligne

## git branch feature/nom_de_la_branche
- Création de la branche

## git checkout feature/nom_de_la_branche
- Se redirriger à une branche

## git checkout -b feature/nom_de_la_branche
- Se redirriger à une branche s'il n'existe pas je la creé

## git pull
- Permet de récupérer les modifications faites en ligne pour les ramener en locale en se positionnant sur la branche
